# Publishing Checklist

## Before creating the GitHub repo

- confirm final repo name
- decide on license
- remove local-only build artifacts
- confirm README language is public-facing

## Before first public push

- verify Java baseline compile/run
- verify Python greedy tests
- verify OR-Tools tests
- confirm sample outputs are committed and intentional
- add one medium test instance

## Before pinning

- add repo description
- add topics such as:
  - `operations-research`
  - `scheduling`
  - `ortools`
  - `java`
  - `python`
  - `optimization`
- ensure the README hero is concise and polished
