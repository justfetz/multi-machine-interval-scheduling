# OR-Tools Java Track

This track mirrors the Python CP-SAT implementation for the multi-machine interval scheduling problem.

It uses:

- `ortools-java`
- a small Maven build inside this folder
- the same CSV input/output contract as the other tracks

## Run

```powershell
.\run-ortools-java.ps1
```

## Test

```powershell
.\run-ortools-java-tests.ps1
```

## Files

- `pom.xml`
- `src/main/java/mmis/ortools/`
- `src/test/java/mmis/ortools/`
